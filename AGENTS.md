# Personal website

This is a public static portfolio. Keep it dependency-free unless a requested feature justifies a change. Use relative asset paths so GitHub Pages project hosting works.

Preserve semantic HTML, keyboard-accessible tabs, readable content without JavaScript, responsive layouts, reduced-motion support, and visible focus indicators.

Use the professional account already in this repository as the source of claims. Clearly distinguish production systems, research prototypes, and planned extensions. Do not publish private source notes, internal employer documents, administrative annotations, credentials, or clinical information.

After changes, check the affected interactions and layout in a browser. Publish reviewed commits through the dedicated `markeyser/personal-website` repository. This repository is separate from any private knowledge vault.
